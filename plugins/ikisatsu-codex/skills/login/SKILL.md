# ikisatsu にログインする

ブラウザで Google ログインを済ませ、フックが使う API トークンを `~/.ikisatsu/token` に保存する。Claude Code のプラグインと同じトークンを使うので、どちらか片方でログインすれば両方で使える。

このスキルのディレクトリから 2 つ上がプラグインのルート。そこにある `bin/login.mjs` を Node で実行する(ブラウザが開く。完了まで最大 5 分待つので、タイムアウトは 6 分以上にする):

```bash
node "<プラグインのルート>/bin/login.mjs"
```

- **サンドボックスの外で実行する承認を求めてから実行する**。ログインは `https://app.ikisatsu.dev` への接続、ブラウザを開くこと、`~/.ikisatsu/` への書き込みが要るので、サンドボックスの中では失敗する
- 終了コード 0 なら成功。表示された email とチーム名をユーザーに伝える。トークンの値は表示されないし、ファイルを開いて確かめようともしない
- ブラウザが自動で開かないときは、コマンドが表示した URL をユーザーに開いてもらう
- 承認が得られない、または失敗(終了コード 1)したときは、表示されたメッセージをそのまま伝え、ユーザー自身の端末で上のコマンドを実行してもらうよう案内する(プラグインのルートの絶対パスを添える)。許可リストに無い email のときは、チームの管理者に追加を頼むよう伝える
- ログイン後、対象リポジトリのルートに `.ikisatsu.json`(`{"projectId": "…"}`)があるときだけ、フックが動く

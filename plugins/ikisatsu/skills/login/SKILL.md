# ikisatsu にログインする

ブラウザで Google ログインを済ませ、フックが使う API トークンを `~/.ikisatsu/token` に保存する。

次のコマンドを Bash ツールで実行する(ブラウザが開く。完了まで最大 5 分待つので、タイムアウトは 6 分以上にする):

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/login.mjs"
```

- 終了コード 0 なら成功。表示された email とチーム名をユーザーに伝える。トークンの値は表示されないし、ファイルを開いて確かめようともしない
- ブラウザが自動で開かないときは、コマンドが表示した URL をユーザーに開いてもらう
- 失敗(終了コード 1)したときは、表示されたメッセージをそのまま伝え、もう一度実行するか聞く。許可リストに無い email のときは、チームの管理者に追加を頼むよう伝える
- ログイン後、対象リポジトリのルートに `.ikisatsu.json`(`{"projectId": "…"}`)があるときだけ、フックが動く
